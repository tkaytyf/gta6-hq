Database · spoilers

All 91 missions

The chapter-by-chapter list follows PC Gamer (91 story missions).

Mission counts vary by site: PC Gamer has 91, Previously has 115 and CutsceneWire has 119. The bigger totals count phone calls, payments and optional steps as missions too.

⚠️ Spoiler warning. Mission names reveal story beats. Open one chapter at a time.

Before you start any chapter

  • There's no mission replay, so make a manual save at the start and end of every chapter. CutsceneWire
  • Four optional missions can be missed for good, though none is needed for a trophy. CutsceneWire
  • Some story calls only come after time passes. If one is stuck, do side activities or install patch 01.002.002, which fixes calls that didn't trigger. GamesRadar+

Step-by-step walkthroughs for each mission are coming soon. Until then, try the spoiler-free VGC walkthrough hub.
